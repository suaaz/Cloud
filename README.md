# ☁️ CloudArchitect.io — Cloud Computing Visual Playbook & Daily Journal

An interactive, visual-first personal website designed to teach and explain **Cloud Computing (AWS, Azure, Google Cloud)** from **Cloud Practitioner (CLF-C02)** to **Solutions Architect (SAA-C03)**. Features crisp architectural SVG blueprints, interactive VPC packet tracing, cloud cost calculators, and an automated daily rotating concept curriculum.

## ✨ Features

- 📐 **Vector Architectural Blueprints (SVG)**: Custom scalable diagrams for the Shared Responsibility Model, Multi-AZ High Availability (ALB + ASG + Multi-AZ RDS), VPC Networking & Stateful vs Stateless Firewalls, Serverless Event-Driven Microservices, and Disaster Recovery RTO vs RPO.
- 🕒 **Automated Daily Cloud Engine**:
  - *Daily Concept Deep Dive*
  - *Beginner Mental Models & Real-World Analogies* (apartment renting, restaurant ticket queues, bouncers)
  - *Cloud Command of the Day* (AWS CLI, Azure CLI, gcloud, Terraform)
  - *Daily Cloud Certification Practice Challenge*
  - *Full Context & Jargon Studio*
- 🔬 **Interactive Cloud Tools**:
  - **VPC Packet Trace & Security Simulator**: Trace packet flow through Internet Gateway, Route Tables, Stateless NACLs, and Stateful Security Groups.
  - **Visual Cloud Cost & TCO Estimator**: Interactive calculator comparing On-Demand vs Savings Plans vs Spot instances with FinOps tips.
- 📚 **Comprehensive Tracks**:
  - **Fundamentals**: Shared Responsibility, Regions & AZs, EC2/VMs, S3/EBS/EFS Storage, VPCs, and IAM least privilege.
  - **Solutions Architect**: High Availability, Decoupling with SQS/SNS, Disaster Recovery strategies, and Terraform IaC.
- ⚡ **Zero-Build Architecture**: 100% static, fast, responsive, and hosted directly on GitHub Pages with zero build dependencies.
